# LoopMaker

LoopMaker 是用于 REAPER 7 的音频循环制作脚本。选中音频 Item 后，它会分析过零点，通过剪辑和交叉淡化生成循环预览；你可以试听、调整参数，再保留可编辑的拼接结构，或胶合成独立 Item。

支持单个循环、多变体、多轨素材、时间选区铺满、自动命名，以及为每段循环创建共享 Region。

## 安装与快速上手

### 运行要求

- REAPER 7，64 位，已安装 ReaImGui。
- 输入为带活动 Take 的音频 Item；不支持 MIDI Item。
- 脚本面向 Windows、macOS 和 Linux；目前原生验证环境为 Windows / REAPER 7.79，不代表所有平台都已验收。

### 安装

1. 在 REAPER 中打开 Options → Show REAPER resource path in explorer/finder。
2. 把完整的 LoopMaker 文件夹复制到资源目录的 Scripts 内。入口脚本、lib 和 ui 必须保持原有目录结构。
3. 若缺少 ReaImGui，在 ReaPack 的 Browse packages 中搜索并安装 ReaImGui: ReaScript binding for Dear ImGui，然后重启 REAPER。
4. 打开 Actions → Show action list，通过 New action → Load ReaScript 加载 LoopMaker/LoopMaker.lua。
5. 可为这个 Action 设置快捷键或工具栏按钮。

更新脚本后，关闭旧 LoopMaker 窗口再重新运行；已经打开的窗口不会自动加载新代码。

### 第一次做一个循环

1. 停止 REAPER 播放或录音。
2. 清除时间选区，选中一个音频 Item。
3. 运行 LoopMaker，保持 Loops = 1，先用默认 Length (%) = 10。
4. 点击 Preview 或按空格试听；使用 **REAPER 的 Stop** 停止播放。
5. 如有明显接缝，调整 Crossfade 的 Length、Curve，必要时微调 Search offset，再试听。
6. 保持 Glue on Apply 勾选，点击 Apply 或按 Enter，得到一个胶合后的循环 Item。

想放弃本轮操作，先停止播放，再点击 Cancel、按 Esc 或关闭窗口。

## 先理解三个概念

| 概念 | 在本工具中的含义 |
|---|---|
| Item | REAPER 时间线上的素材块。一个输入 Item 通常对应一个音频来源；多轨选中多个 Item 时会分别处理。 |
| 变体（variation） | 从同一输入素材的不同取料区间生成的循环版本。顶部 Loops 主要控制每个 Item 的变体数量。 |
| 排列段（slot） | 时间选区内的一段输出位置。多个段可以重复使用同一个变体；同一段也可以包含多个轨道的声音。 |

**Loops、最终 Item 数量、Region 数量不是同一个概念。** 例如两个轨道共同铺满 12 段，每段各有一条胶合后的 Loop，会得到 24 个输出 Item；如果两轨每段起止位置相同，开启 Region 后会创建 12 个 Region。

### 有时间选区与没有时间选区

| 操作前的状态 | 输出方式 |
|---|---|
| 没有时间选区，Loops = 1 | 使用每个 Item 的可用范围制作一个循环。交叉淡化会让最终循环短于取料区间，不保证保留原始时长。 |
| 没有时间选区，Loops > 1 | 将每个 Item 分成多个取料区间，生成不同变体，从该来源原位置开始排列。 |
| 有时间选区 | 用统一长度的循环段连续铺满选区，变体不足时重复使用。多轨共用排列段和变体序列。 |

**时间选区定义整段输出的覆盖范围，不是每个 Loop 的长度。** 只制作素材自身的循环时，运行前先清除时间选区。

当前铺满规则要求每段样本数相同，并精确填满量化后的选区。为了满足整除关系，程序可能增加段数、缩短循环；即使 Loops 很小，也可能出现很多短段。在 Position 中可查看实际段数和每段时长。

运行期间修改时间选区，会在下一次参数重建时被读取；单独拖动选区不保证立即重建。Cancel 会恢复启动时的时间选区。

## 顶部操作与选项

顶部固定显示主操作，滚动或折叠下方参数区时仍可使用。

### Create regions on Apply：为循环创建区域

**默认：关闭。** 位于右上角、Glue on Apply 左侧。

勾选后，点击 Apply 时为每段最终循环创建一个 REAPER Region，方便按段定位和组织后续渲染。

- 起点和终点在采样对齐后相同的多轨 Loop，共用一个 Region。
- 只有起点相同、终点不同，或仅仅时间重叠，不会合并为同一 Region。
- 名称使用同组首个来源的命名设置，并按时间顺序编号。
- 时间选区中的重复段也会各建一个 Region，不只为唯一变体创建。
- 预览期间不创建；Cancel 不留下本次 Region；成功 Apply 后可与 Item 一起撤销。
- 既有 Region 会保留。本选项不会设置渲染矩阵、选择导出路径或导出文件。

**怎么用：** 设置好 Loops、命名和排列，勾选此项，再 Apply。两轨同一段若均从 10 秒到 15 秒，会共用一个覆盖 10–15 秒的 Region。

### Glue on Apply：胶合输出

**默认：开启。**

| 状态 | Apply 后的结果 | 适合用途 |
|---|---|---|
| 开启 | 对每个循环调用 REAPER 原生 Glue，将拼接组件合成为一个 Item。 | 方便移动、整理和后续渲染。 |
| 关闭 | 保留组成循环的多个可编辑 Item 及其淡化。 | 继续手动检查和调整拼接点。 |

多轨分别胶合，不会因为共用 Region 就混成一个音频文件。Glue 与 Region 开关相互独立，可以同时开启。

预览阶段不生成 Glue 文件。Glue 的文件位置、格式等受 REAPER 当前设置影响；本工具没有独立的导出设置面板。

### Loops：每个 Item 的循环变体数量

**默认：1。普通模式范围：1–1000。**

拖动滑块快速调整；右侧数字框可以精确输入，也可使用旁边的减号、加号。快速滑块初始范围为 1–32，输入更大值后会扩展。

数字越大，每个变体可用的素材区间越短。普通多变体模式要求每个取料区间至少 24 ms，超出素材承受范围会报错。

**怎么用：** 想从一段风声中做几个不同版本，可先设为 3 或 5，再试听每个版本。若只想延长覆盖时间，建立时间选区即可，不必把 Loops 设置为重复次数。

Shepard 模式下，Loops 改为控制叠加层数，见实验功能说明。

### Preview、Apply、Cancel 与快捷键

| 操作 | 快捷键 | 作用与用法 |
|---|---|---|
| Preview | 空格 | 从预览范围起点开始循环试听。用 REAPER Stop 停止；再次按 Preview 不负责停止正在播放的 REAPER。 |
| Apply | Enter / 小键盘 Enter | 保留结果，并执行已勾选的 Glue、Region 操作。先停止播放，等待预览更新完成。 |
| Cancel | Esc | 放弃本轮生成结果，恢复启动时捕获的状态。先停止播放。 |
| 关闭窗口 | — | 按取消流程恢复。先停止播放或录音再关闭。 |

输入框或其他控件正在编辑时，全局快捷键不会触发；例如输入框里的 Enter 不会同时提交整个循环。

## 预设管理

预设保存当前参数，便于重复使用一组设置；不会保存输入音频或替你建立时间选区。

| 控件 | 作用与使用方式 |
|---|---|
| 顶部预设下拉框 | 选择已有名称以加载参数，随后检查更新后的预览。 |
| Default | 加载内置默认值。想从默认参数重新开始时选择它；不能删除。 |
| Manage | 展开或收起名称、保存和删除控件。 |
| Preset name | 输入要保存的预设名称，例如 Wind_Loops。 |
| Save / overwrite | 保存当前设置，或覆盖同名用户预设。先调好参数、填好名称，再点击。 |
| Delete | 删除下拉框中当前选中的用户预设；删除后返回 Default。 |

预设保存在本机 REAPER ExtState 中，不随工程文件自动转移到其他电脑。加载预设也会带入 Glue、Region 等选项，Apply 前可再次确认顶部勾选状态。

## Position：位置与排列

### Position space (s)：循环之间的间隔

**默认：0 秒。界面范围：0–60 秒。**

控制没有时间选区时，相邻输出循环之间的空隙。0 表示连续排列；1 表示每段之间留 1 秒。

**怎么用：** 制作便于逐个试听和整理的素材库时，可留出间隔。连续铺满场景时使用时间选区。

有时间选区时控件禁用，实际间距为 0；此前设置的间隔值仍会保留。

### Shuffle variation positions：打乱变体排列

**默认：关闭。**

改变变体排列顺序，不增加新的音频内容，也不增加唯一变体数量。

铺满时尽量均衡使用各个变体：出现次数最多相差 1，并尽可能避免相同变体紧邻。多轨共享同一序列，维持层间对应关系。

**怎么用：** 有多个变体且重复感明显时勾选，再试听整体排列。只有一个变体时，打乱不会带来内容变化。

### Snap boundaries to seconds：取料边界吸附到整秒

**默认：关闭。**

将源素材取料边界吸附到整秒位置。它不是对齐节拍、小节，也不是把最终输出强制变成整数秒。

**怎么用：** 需要按整秒划分源素材时启用。若提示无法同时保持等长、唯一和整秒边界，关闭此项或调整素材范围、Loops。

时间选区铺满还会进行采样对齐和长度适配，因此不能保证最终边界仍是整秒。

### Match overlapping item lengths：匹配跨轨重叠素材的循环长度

**默认：关闭。**

对跨轨且时间上重叠的来源分组，将组内可用循环长度匹配到共同的较短长度。它用于协调层间长度，不会把多轨混成一条，也不表示所有原 Item 会被移到同一起点。

**怎么用：** 多层环境声需要相同循环长度时开启。希望不同素材各自保留可用长度时关闭。

有时间选区时，铺满逻辑本身会统一最终段长；即使未勾选，多轨仍共用铺满段的位置。素材边界或固定过零点无法容纳匹配长度时，可能提示错误。

### Fill time selection：铺满信息

存在时间选区时显示以下只读信息：

| 显示内容 | 含义 |
|---|---|
| unique variations | 唯一变体数量，不包含重复排列次数。 |
| timeline slots | 时间线上的实际排列段数。 |
| samples each | 每段包含的样本数。 |
| s per slot | 每段时长，单位为秒。 |
| s total | 整段输出覆盖时长。 |

输出比预期更碎时，先查看这里，而不是只看顶部 Loops。

## Crossfade：交叉淡化

两个片段在重叠区内一边淡出、一边淡入，用于减轻拼接处的突变。此分区只用于普通循环模式。

### Length (%)：淡化长度比例

**默认：10%。范围：0–50%。**

拖动滑块调整，也可 Ctrl+点击输入精确数值。

当前实现按**取料区间长度**计算名义淡化长度，再受 Max length、过零点位置和安全边界约束。最终循环长度是取料区间长度减去实际重叠长度。

例如，10 秒取料区间设为 10%，在边界允许且没有额外上限时，重叠约 1 秒，最终循环约 9 秒。结果还可能因边界分析、变体长度匹配或选区铺满而调整。

**怎么用：** 接缝明显时尝试增加；瞬态被拖软或明显叠音时尝试减小。0% 表示不使用主交叉淡化，但多变体输出仍可能保留安全淡化。

### Curve：淡化曲线

**默认：Linear (0)。可选：Linear (0)、REAPER curve 1–4。**

控制重叠区内音量随时间变化的方式，不改变 Loops 数量。

**怎么用：** 先使用 Linear。若重叠处音量下陷或隆起，逐个比较其他曲线，选择音量和音色更自然的一种。曲线沿用 REAPER 编号，没有对所有素材都最好的固定选项。

### Max length (s)：淡化时长上限

**默认：0，即 No limit。界面范围：0–60 秒。**

限制交叉淡化的最长时长，避免长素材按百分比计算后产生过长重叠。设为 0 只取消额外上限，**不代表关闭淡化**。

**怎么用：** 想保留 10% 比例、但淡化不超过 0.5 秒，设置为 0.5。比例算出的淡化本来更短时，不会被拉长到 0.5 秒。

### 淡化与输出长度

- 增加淡化比例可能缩短自然循环长度，并间接改变选区铺满段数。
- 适配较短的铺满段时，在素材边界允许的范围内围绕过零点对称取料，使不同轨道主淡化位于段内中央；边界不足时使用受限的安全方案。
- 普通多变体模式保留 3 ms 外边界安全 Fade；Glue 会把淡化写入音频。
- 外边界安全 Fade 与主交叉淡化不同。它能降低爆点风险，但不能保证任何素材、任何变体切换都完全无感。

## Zero-Crossing：过零点

过零点是波形经过零振幅附近的位置。在附近选择拼接点有助于减少波形突然跳变；多声道和复杂相位素材仍需要试听。

### Search offset (s)：搜索中心偏移

**默认：0 秒。界面范围：−60 到 +60 秒。**

相对于计划边界移动过零点搜索中心。正值向后，负值向前；单位是秒，不是百分比，也不是整体移动输出 Item。

**怎么用：** 接缝附近有敲击、节奏点等突出特征时，从较小偏移开始调整并试听。偏移受可用取料区间限制，超出边界会被限制并显示提示。

### 分析列表与 Show more boundaries

| 显示或控件 | 作用与使用方式 |
|---|---|
| analyzed boundaries | 当前分析条目数。 |
| 素材名、#编号、时间范围 | 对应来源与变体的边界分析信息。时间为工程中的秒数，不应把这里的时间差当作最终 Loop 长度。 |
| Show more boundaries | 初始最多显示 20 条，每次点击再显示 20 条。 |
| No analyzed boundaries | 当前没有可显示的分析结果。 |

找不到合适过零点时，程序可能使用回退目标并显示 Warnings。回退不等于结果已经通过听感验收。

## Name：命名与颜色

名称优先取输入 Take 名称；不可用时回退到源文件名或默认名称。命名用于输出 Take / Item 显示和 Region，不能据此保证磁盘文件一定采用相同名字。

| 选项 | 默认值 | 作用与使用方式 |
|---|---|---|
| Color items | 关闭 | 为输出 Item 应用脚本预设蓝色，便于辨认结果。没有自定义选色器，也不是每个变体随机一种颜色。启用 Region 时也会使用该颜色。 |
| Remove extensions | 关闭 | 去掉来源名称最后一个扩展名，例如 wind.wav → wind。只改名称，不转换文件格式。 |
| Prefix | 空 | 在名称最前面加文字，例如 ENV。留空则省略。 |
| Suffix | 空 | 在名称最后面加文字，例如 Loop。留空则省略。 |
| Separator | 下划线 _ | 各部分之间的分隔符。这是文本输入框，可输入下划线、短横线、空格，也可清空。 |
| Add number | 开启 | 将变体编号加入名称。关闭后隐藏起始编号和补零设置，原值仍保留。 |
| Starting number | 1 | 第一个编号，范围 0–999999。需要接续已有素材编号时修改。 |
| Leading zeros | 2 | 编号最小位数，范围 0–12。2 表示 01、02；3 表示 001、002。不截断更长数字，0 表示不补零。 |

### 命名示例

实际顺序为：**前缀 → 来源名称 → 编号 → 后缀**，空的部分会省略。

来源为 wind.wav，开启 Remove extensions，Prefix 设为 ENV，Suffix 设为 Loop，Separator 使用下划线，开启 Add number，Starting number = 1，Leading zeros = 2。

结果为：**ENV_wind_01_Loop、ENV_wind_02_Loop、ENV_wind_03_Loop**。

每个来源按自己的变体编号；时间选区中同一变体的重复 Item 可以同名。Region 按输出段的时间顺序编号，因此重复段的 Region 编号与 Item 变体编号可能不同。

## Shepard Tone：实验性音高效果

这是低优先级实验功能，普通音效循环保持关闭即可。

| 控件 | 默认值 | 作用与使用方式 |
|---|---|---|
| Shepard Tone (experimental) | 收起 | 展开实验参数。仅展开面板不会启用效果。 |
| Enable Shepard Tone | 关闭 | 勾选后切换到叠层音高效果模式，取消后返回普通循环。 |
| Pitch (semitones) | +12 | 音高变化方向与幅度，单位为半音，范围 −96 到 +96。正值上行、负值下行，可先比较 +12 和 −12。 |
| 顶部 Loops | 范围改为 1–6 | 层数为 2 的 Loops 次方，例如 1 对应 2 层、3 对应 8 层、6 对应 64 层。 |

目标是形成类似持续上升或下降的听觉效果，结果依赖素材。整八度变化通常更容易形成连续边界；非整八度设置可能显示提示。普通 Crossfade 与 Zero-Crossing 控件在此模式不适用。

## 常见使用流程

### 从一个素材制作多个独立循环

1. 清除时间选区，选择一个音频 Item。
2. 运行脚本，把 Loops 设为所需变体数。
3. 用 Position space 留出间隔，方便逐段试听。
4. 调整 Length、Curve 和 Search offset。
5. 在 Name 中设置后缀和编号。
6. 勾选 Glue；需要区域标记时再勾选 Region，然后 Apply。

### 用短素材铺满一段场景

1. 建立需要覆盖的时间选区，例如 60 秒。
2. 选中音频素材，运行脚本。
3. 设置几个唯一变体，需要变化顺序时开启 Shuffle。
4. 在 Position 检查实际段数和时长。重复排列由工具处理，Loops 不需要等于播放次数。
5. 试听整段，停止播放后 Apply。

出现大量短段时，减少 Loops、减小淡化比例或调整选区长度，再观察段数。这些调整可能改善结果，但整除规则仍可能限制段长。只需要输出素材变体时，清除选区后重新生成更直接。

### 多轨分层循环并共用 Region

1. 同时选中需要处理的多轨音频 Item。
2. 需要所有轨道覆盖同一场景时，先建立时间选区。
3. 运行脚本，调节 Loops 与 Crossfade，检查各轨结果。
4. 勾选 Create regions on Apply；想要每轨每段一个完整 Item 时，同时勾选 Glue。
5. Apply 后，起止相同的多轨输出共用 Region。如何渲染为分轨文件或混合文件，在 REAPER 中另行设置。

没有时间选区时，Match overlapping item lengths 可帮助匹配跨轨重叠素材长度，但不同起点不自动等同于同一个 Region。

### 准备游戏引擎循环资产

先输出并试听唯一变体，再在目标引擎验证连续循环与随机切换。重复使用的同一变体，不必仅因为位于另一个排列段就当作新的独立资产。

本工具不直接配置 Wwise 或其他引擎。相同样本数、过零点和安全淡化仍不能保证任意变体切换都无感，应实际检查爆点、音量起伏和突出特征重复。手工验收要求见文末链接。

## 状态提示与故障排查

### 界面状态

| 提示 | 含义与下一步 |
|---|---|
| Preview ready / Ready | 预览可用，可以试听或继续调节。 |
| Updating preview... | 参数已变化，等待重建完成。 |
| Filling time selection · N slots | 正在铺满时间选区，N 是实际排列段数。 |
| Stop playback in REAPER to update or finish. | 先停止播放或录音，再重建、Apply 或 Cancel。 |
| Warnings (N) | 点击展开查看。可能是长度匹配、淡化缩短或过零点回退，不一定代表整批失败。 |
| Error: ... | 当前操作失败，按具体信息排查。没有有效预览时不能 Apply。 |

### 常见问题

| 现象 | 排查与处理 |
|---|---|
| 提示缺少 ReaImGui | 安装 ReaImGui 并重启 REAPER。 |
| Apply / Preview 变灰 | 停止播放、等待更新，并检查是否有有效输出及顶部错误。 |
| Loops = 3，却出现很多 Item | 检查时间选区。铺满会重复排列；关闭 Glue 时，一个循环本身还由多个拼接 Item 组成。 |
| 每段比原素材短 | 淡化重叠消耗时长；多变体、长度匹配和铺满也可能缩短输出。 |
| Region 没有马上出现 | 只在 Apply 时创建，预览期间不创建。 |
| 多轨出现重叠的不同 Region | 检查各轨输出的起点和终点是否都相同；仅重叠或同起点不会合并。 |
| 调整 Glue / Region 后波形没变化 | 正常，这两个选项只影响 Apply 阶段。 |
| 改了时间选区，预览没有更新 | 下次参数重建时才读取；调整一个音频参数触发重建，或取消后重新运行。 |
| 有爆点、重叠变响或音量下陷 | 比较淡化比例与曲线，微调搜索偏移，查看是否发生回退，再试听接缝。 |
| 提示素材范围越界 | 检查 Item 是否超出底层音频可用范围，尤其是拉长、变速或特殊源处理后。可裁到有效范围，或另做胶合副本后重试。 |
| Loops 太多时失败 | 减少数量或使用更长素材，普通多变体取料区间至少需要 24 ms。 |
| Glue 失败 | 检查具体错误与 REAPER 媒体设置。失败时可能已生成文件，项目恢复不会保证删除磁盘文件。 |
| 更新后看不到新界面 | 关闭旧窗口，确认更新了 Actions 实际加载的目录，再重新运行。 |
| 异常后状态未恢复 | 暂停继续编辑，检查 REAPER Undo，保留错误信息用于排查。 |

## 撤销、恢复与使用边界

- 停止播放或录音再启动；调整参数、Apply 或 Cancel 前也先停止 REAPER。
- 预览会在工程中临时创建拼接结果，重建时先恢复基线再生成，避免累积。
- Cancel 恢复启动时捕获的 Item、选择、时间选区、循环点、Repeat 和编辑光标等；成功 Apply 后可用一次 REAPER Undo 撤销结果。
- 避免在脚本预览期间进行大量手动编辑。切换项目会触发恢复处理，有异常时回到原项目核对。
- 铺满结果会放入所选来源轨道和目标选区，可能与该位置其他素材重叠，提前确认目标位置是否适合放置输出。
- 素材越界或过零点靠近边缘时，可能需要缩短淡化、减少 Loops 或调整素材范围。
- Region 是时间范围标记，不包含音频，不会把多轨混成一个声音。
- 项目撤销与磁盘文件清理不同，Glue 文件可能在失败或撤销后仍保留。
- 多声道、强瞬态、明显节奏或复杂相位素材需要实听，自动检查不能代替听感验收。

### 铺满采用的采样率

程序依次使用：项目已启用的采样率、当前音频设备采样率、所有选中来源一致的源采样率。无法取得可靠值时会提示错误。

所有段使用相同整数样本数，最后一段结束在量化后的选区终点。当前不支持用长短相差一个样本的段来减少碎片数量。
